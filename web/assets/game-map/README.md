## 本次要求与处理

外围道路、路名和原始排版按用户提供图片保留。园内修正北大山草坪、梅园与一尺花园、鲁迅墓、湖心岛、中日友好钟座、纪念亭、纪念馆、儿童游乐区的相对方位。区分鲁迅纪念亭与上海鲁迅纪念馆。此图属于活动示意图，景观符号与步道采用手绘表达，不属于实测地图。

图像制作使用内置 image_gen 编辑工具。最后保留原图外围像素，并检查保留区域与原图无像素差异。原图外围道路没有按现实道路重新绘制。

以用户原图为编辑目标，官方导览与按该导览描绘的参考图只用于园内相对布局；所有外围道路及路名保持原图。北部改为北大山草坪，墓居中部偏西，梅园与一尺花园在墓东北，湖心岛在梅园东侧且南北高度接近，钟座在墓东侧接近同一高度，馆在东南，亭与馆分开，游乐区在西南。保留水彩风格、象牙色标签与清晰中文，不新增未核验的湖心亭/荷花池等命名地标。
