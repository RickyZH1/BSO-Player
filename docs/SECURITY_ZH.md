# 安全边界与上线检查

## 公开与私密

GitHub仓库及GitHub Pages均公开。只有网页源码、通用算法、数据库结构、无身份信息的工具脚本和公开素材可放进去。

私密规则、完整队伍布局/美食数据的可下载种子、账号邮箱密码只在信任电脑的.private目录生成，再导入受限Supabase表。Pages产物只有dist；构建不会包含.private、scripts、SQL、测试或文档。工作人员前端也是公开程序，但只在Staff认证后从受限接口取规则，源码本身没有规则全文或答案。

管理员密钥可以绕过RLS，绝不能使用在浏览器。此仓库只有用户允许公开的publishable key。不要把数据库密码误当成网页账号密码或API key。

## 权限实现

- profiles以auth.uid映射身份，不读取客户端自报role/team_id或Auth user_metadata角色。
- 业务表全部RLS开启、anon无权；authenticated只有必要SELECT，不给INSERT/UPDATE/DELETE。
- team和staff同样不能直接改余额/任务/阶段表。写入只走portal_action。
- SECURITY DEFINER函数固定空search_path，并使用全限定表名，业务入口每次重新验证active身份。
- private helper不暴露为API；只有必要的RLS身份/图片访问辅助函数可执行。不要把private schema加入Data API exposed schemas。
- 玩家portal_read只拼装本队数据；Staff机密仅Staff分支返回。玩家不会收到其他五队卡面和成绩。
- bingo_claims原表只许Staff SELECT，玩家走裁剪后的快照，无rank/global ordinal。photo_submissions不给玩家全局ordinal列权限，防止通过共享序列推测其他队提交顺序。
- 食物行须本队且已解锁；线索行须已统一放行。不是CSS隐藏。
- 所有敏感写入使用事务级锁、幂等请求、唯一约束和审计；错误整笔回滚。时间戳在服务器锁内确定，不使用客户端时间。

## Storage

evidence是私有bucket；插入必须匹配当前Team的服务器预留随机key，预留10分钟过期，正在比赛且未到截止。不能任意指定其他队路径；不存在客户端UPDATE/DELETE策略，防止提交后替换图片。

仅本队/Staff能读记录对应图片；查看用60秒签名URL。签名是短期持有凭证，谁拿到它在有效期内都可能访问，所以不转发到公共聊天。停用账号不能立即使已经发出的签名失效，但最多60秒过期。

桶限制800000 bytes及JPEG/WebP类型。正常页面压缩最长边1600、重绘为JPEG以去除EXIF；客户端压缩不能证明恶意客户端也去除了EXIF，审核仍是人工，不宣称服务端进行了图像真实性或EXIF检查。证据可能含人像，主办方应告知用途、访问范围与保留时间。

限制每队每目标每分钟最多3次预留，每队总预留最多120次；预留失败也占次数，避免无限孤儿文件。如果极端失败耗尽上限，由项目拥有者核对日志处理；没有面向玩家的无限重置入口。

## 原Game站点保密阻断项

旧站公开完整工作人员手册，且旧GitHub历史里仍可能存在相同内容。新站权限无法让旧页面自动保密。

项目未修改或删除旧站。上线前由总控明确决定：

1. 先在安全电脑保存.private数据、Game源文件和公开地图/目标图备份，并确保新站已复制公开素材。
2. 将工作人员规则迁入本项目受限staff_rules，并用Team账号实测无法读取。
3. 对旧Pages停止公开发布或仅保留不含秘密的公共页面。
4. 对旧仓库改为私有或按GitHub流程清理敏感历史；仅删除首页、删导航、JS密码框、robots.txt或“不分享链接”都不足以保密。
5. 旧内容已被第三方缓存/复制的风险不能靠新站收回。若有高敏题目在旧站出现，应由总控评估更换题目，但不能私自改变既定计分规则。

源素材导入固定引用历史提交；旧仓库转私有/清理后未来自动重建会无法拉取。请先把允许公开的地图及目标图存入本仓库可跟踪的素材目录并调整build脚本，或使用安全备份进行构建；不能为了让构建继续而重新公开Staff手册。

## 账号与审计

六队共享登录无法识别同队具体哪位成员点击上传/申报，日志记录Team账号身份；这是共享账号的固有边界。工作人员独立登录，能记录实际审核人。没有声称共享账号具备个人级玩家审计。

使用profiles.active停用可立即禁止新的业务访问；项目拥有者权限仍能直接改数据库，这是Supabase管理边界，不等同于网页Staff权限。正常运营不要用Table Editor改分或删除流水。

CSV对以=、+、-、@等开头的字符串作前缀处理，避免在Excel打开时执行公式。文本输出HTML转义，图片只允许HTTPS/同源路径。

## 真实部署必须验收

开发CI以PostgreSQL模拟Supabase Auth和Storage schema，不能代替真实JWT、Storage上传/签名网关。至少两队及两名独立Staff实测，并依TEST_PLAN_ZH完成全部八名Staff、网络及设备检查。

仅以“RLS开关已打开”“前端没有按钮”“public key不是secret”或“CI绿色”为上线安全结论都不够。
