## 实施顺序与验收

M1：迁移、RLS、角色映射、固定卡面、Staff任务审核、服务器计分与流水、统一开场、放行、公告与线索编辑、15秒同步。

M2：私有照片与First Finder、去重及五图完成、队伍美食、Bingo资格与有序授奖、截止/纠错/CSV、测试与中文文档。

数据库实体来自PRD，同时增加task_evidence（Staff成绩原始输入）及private.requests（重试幂等记录）。原规则与各队私密清单不复制到公开仓库：初始化时在信任的电脑生成.private/seed.sql，再在Supabase SQL Editor导入。

运行方式采用轻量原生JavaScript，esbuild将Supabase SDK打包为本地静态文件，避免现场依赖外部JS CDN。相对路径适配 /BSO-Player/；页面内部Tab不使用路径路由，刷新不会产生子页面404。
