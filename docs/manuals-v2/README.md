## 怎样看
1. 点击PDF打开预览；需要保存时使用GitHub文件页的下载按钮。
2. PDF第2页目录可点击跳转，也可以搜索按钮或阶段名称。
3. 压缩包解压后双击“打开图解手册.html”，按手册和章节切换。
4. 图片文件夹中的单页PNG可分别发给活动群。

每页说明操作平台、入口、适用阶段、目的、编号步骤、注意事项和完成检查。
截图复用上一版演示界面；Supabase菜单流程是明确标记的位置示意图，不是真实后台截图。
手册不含真实账号密码、秘密地点、正式题库答案或真实队伍卡面。工作人员秘密规则仍只能从受限后台读取。

## 数据重置
只用于全部六队业务记录都是测试、活动日期之前。正式记录用更正／撤销留痕。
有照片先私密备份，再在Storage界面删除evidence实际文件；保留桶和权限，不用SQL直接删除storage.objects。
[只读检查SQL](reset-files/01_precheck.sql) → [带确认保护的重置SQL](reset-files/02_reset_rehearsal.sql) → [验收SQL](reset-files/03_verify_reset.sql)。
确认变量默认“未确认”，只有主办方确认全部为测试后才按手册改指定文字。
